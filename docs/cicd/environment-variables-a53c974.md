# Environment Variables

Find information on the predefined environment variables supported by SAP Continuous Integration and Delivery and how to use them.

The following table provides an overview of the predefined environment variables you can use with the Continuous Integration and Delivery service:

**Environment Variables for SAP Continuous Integration and Delivery**


<table>
<tr>
<th valign="top">

Variable

</th>
<th valign="top">

Description

</th>
</tr>
<tr>
<td valign="top">

`CI` 

</td>
<td valign="top">

Indicates whether the job is running in a continuous integration environment. Always set to `"true"` when executed by SAP Continuous Integration and Delivery.

</td>
</tr>
<tr>
<td valign="top">

`SAPCID_API_SELF_LINK` 

</td>
<td valign="top">

A link to the build run’s resource in the SAP Continuous Integration and Delivery API.

</td>
</tr>
<tr>
<td valign="top">

`SAPCID_BUILD_CONFIG_JSON` 

</td>
<td valign="top">

A collection of structured properties that are useful for your job.

</td>
</tr>
<tr>
<td valign="top">

`SAPCID_BUILD_ID` 

</td>
<td valign="top">

A unique identifier for the build run, generated by the service for each execution.

</td>
</tr>
<tr>
<td valign="top">

`SAPCID_BUILD_NUMBER` 

</td>
<td valign="top">

A sequential build number that increments with each new execution of the job.

</td>
</tr>
<tr>
<td valign="top">

`SAPCID_GIT_HEAD` 

</td>
<td valign="top">

Contains the commit SHA of the revision checked out for the build.

</td>
</tr>
<tr>
<td valign="top">

`SAPCID_GIT_REFERENCE` 

</td>
<td valign="top">

Specifies the Git reference \(branch, tag, or commit SHA\) on which the job was triggered.

</td>
</tr>
<tr>
<td valign="top">

`SAPCID_GIT_URL` 

</td>
<td valign="top">

The URL of your source repository.

</td>
</tr>
<tr>
<td valign="top">

`SAPCID_JOB_NAME` 

</td>
<td valign="top">

The name of the job that is being executed.

</td>
</tr>
<tr>
<td valign="top">

`SAPCID_RESULT` 

</td>
<td valign="top">

Indicates the current result of the build.

</td>
</tr>
<tr>
<td valign="top">

`SAPCID_PIPELINE` 

</td>
<td valign="top">

Pipeline type that is currently being executed.

</td>
</tr>
<tr>
<td valign="top">

`SAPCID_PIPELINE_VERSION` 

</td>
<td valign="top">

Indicates the version of the pipeline configuration used for the current build.

</td>
</tr>
<tr>
<td valign="top">

`SAPCID_TARGET_BRANCH` 

</td>
<td valign="top">

Specifies the target branch to be checked out.

</td>
</tr>
<tr>
<td valign="top">

`SAPCID_UI_SELF_LINK` 

</td>
<td valign="top">

Provides a link to the build information page in the SAP Continuous Integration and Delivery user interface.

</td>
</tr>
</table>
